# Typography

## Font strategy
Use a clean sans-serif font that works well in Flutter and supports English plus Indian language fallbacks where needed.

## Recommended fonts
- Primary: Inter
- Fallbacks: Roboto, Noto Sans, system sans-serif

## Type scale
- Display Large: 32 / 40 / 700
- Display Medium: 28 / 36 / 700
- Headline Large: 24 / 32 / 700
- Headline Medium: 22 / 30 / 600
- Title Large: 20 / 28 / 600
- Title Medium: 18 / 24 / 600
- Body Large: 16 / 24 / 400
- Body Medium: 14 / 20 / 400
- Label Large: 14 / 20 / 600
- Label Medium: 12 / 16 / 600

## Usage rules
- Use strong headings for section clarity.
- Do not use more than 5 text roles on one screen.
- Body text must stay readable for school-age users and parents.
- Avoid light font weights for important text.
- Use Title Medium or Label Large for buttons, tabs, chips, and interactive labels.

## Content rules
- Headlines should be short and clear.
- Cards should use one strong title and one supportive subtitle.
- Parent-facing copy should avoid jargon when possible.
