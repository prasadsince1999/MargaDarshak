# Material 3 Expressive Adaptation

## Reality check
Flutter supports standard Material 3 well, but Material 3 Expressive is not a first-class built-in Flutter feature yet. The project should use standard Material 3 as the base and add a controlled expressive layer manually.

## Use standard M3 for
- ColorScheme
- typography structure
- navigation bars
- buttons
- cards
- dialogs
- menus
- bottom sheets

## Add expressive feel manually through
- stronger visual hierarchy
- larger, friendlier section titles
- rounded surfaces with clear personality
- richer but calm motion
- clearer card grouping
- stronger onboarding and roadmap presentation
- meaningful empty states and status visuals

## Avoid
- copying Android Compose-only APIs blindly
- over-designing every screen
- excessive motion
- random playful shapes that reduce trust

## Product-specific expressive cues
- Journey timeline visuals
- “you are here” markers
- stage chips with soft color groups
- parent vs student mode visual distinction
- calm mentor cards with stronger presence than ordinary cards
