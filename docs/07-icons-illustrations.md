# Icons and Illustrations

## Icon style
- Rounded or softly geometric icons
- Consistent stroke width
- Use one icon family only

## Suggested icon sets
- Material Symbols Rounded
- Lucide (if custom set needed but use consistently)

## Icon sizes
- Small: 16
- Medium: 20
- Standard: 24
- Large: 32

## Rules
- Every icon should support meaning, not decoration only.
- Pair icons with labels for important actions.
- Use status icons consistently.

## Illustration style
- Minimal, calm, student-relevant
- Use illustrations for onboarding, empty states, and parent awareness screens
- Avoid cartoon overload
