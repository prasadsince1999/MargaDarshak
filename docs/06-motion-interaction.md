# Motion and Interaction

## Motion principles
- Motion should improve clarity.
- Keep transitions calm and quick.
- Avoid decorative chaos.
- Use animation to show hierarchy, expansion, progress, or feedback.

## Duration tokens
- Fast: 120ms
- Standard: 200ms
- Slow: 280ms
- Screen transition: 300ms

## Interaction rules
- Buttons need visible press feedback.
- Cards with navigation should show pressed state or slight elevation change.
- Expand/collapse cards should animate height and opacity.
- Use skeleton loading for data-heavy screens.

## Recommended motion moments
- Onboarding step changes
- Tab switching
- Roadmap stage expansion
- Eligibility state reveal
- Bottom sheet entry
- Snackbar feedback

## Avoid
- Overuse of bounce effects
- Long hero animations before content
- Auto-playing motion that distracts from guidance content
