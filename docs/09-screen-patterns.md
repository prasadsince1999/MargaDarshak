# Screen Patterns

## Home
Structure:
- stage banner
- next best action
- roadmap confidence
- quick check
- deadline/document alert
- Student Voice prompt (if eligible)
- Family Bridge alert (if linked)

## Roadmap
Structure:
- explore paths
- my plan (Plan A / Plan B)
- compare
- eligibility
- exams
- courses
- colleges + Student Voice Score
- skill check
- resources

## Profile
Structure:
- basic details
- stage/stream/board/state
- parent-child link
- my saved plans
- my feedback submissions
- my verification level
- consent/privacy controls

## Career Detail
Structure:
- role summary
- subjects needed
- degree path
- exams
- private + government opportunities
- time/cost reality check
- backup routes

## Compare Screen
Structure:
- compare selector
- cards/table
- trust score + student voice score
- suitability notes
- sponsored disclosure (if applicable)
- next action

## Institution Detail
Structure:
- institution summary
- accreditation status + verification badge
- Student Voice Score breakdown
- Parent Trust Score breakdown
- fee structure
- placement data
- safety rating
- sibling recommendation %
- report wrong data button

## Student Voice Submit
Structure:
- select institution/course
- verification level indicator
- dimension-based survey questions
- anonymous toggle
- submit + moderation notice

## Verified Skill Check
Structure:
- supervision mode selector
- subject/topic selection
- assessment interface
- results + foundation report
- confidence score impact
- AI explanation of weak areas

## Parent Mode
Structure:
- child stage summary
- metrics row (suitability / risk / backup count / ROI)
- recommended path card
- module carousel (myth / discussion / scholarships / deadline / pair)
- child profile action
- exam alerts link

## Family Bridge
Structure:
- shared saved paths
- path comparisons
- family discussion prompts
- next family action summary

## Admin HUD
Structure:
- data management (roadmaps, courses, exams, institutions, scholarships)
- verification queue
- survey management
- assessment question bank
- feedback moderation
- sponsored partner management
- analytics dashboard
