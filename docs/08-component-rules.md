# Component Rules

## App bar
- Clear title
- Optional short subtitle
- Back only when needed
- Actions kept minimal

## Buttons
### Primary button
- Used for main action on a screen
- Filled with primary color

### Secondary button
- Tonal or outlined
- Used for alternate safe action

### Text button
- Used for low-emphasis actions

## Cards
### Mentor card
- Shows current stage, next step, or recommendation

### Status card
- Shows eligible / caution / blocked state

### Roadmap card
- Stage title, short explanation, next step CTA

### Resource card
- YouTube/free resource link, type label, save action

## Inputs
- Use clear labels
- Avoid placeholder-only forms
- Add helper text for confusing fields like stream/board/category

## Chips
- Interest chips
- Subject chips
- Eligibility tags
- Exam type chips

## Tabs
Use only for sibling sections such as:
- Student / Parent
- Overview / Details
- Government / Private

## Bottom sheets
Use for:
- filters
- path comparison quick view
- save/share options
- parent explanation summary

## Banners
- Use info banner for official verification notices
- Use warning banner for missing eligibility or deadline risk

## Empty states
Must include:
- clear explanation
- supportive tone
- one visible action
