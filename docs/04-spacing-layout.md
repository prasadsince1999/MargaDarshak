# Spacing and Layout

## Base system
Use an 8-point spacing system.

## Spacing scale
- 4 = micro gap
- 8 = small gap
- 12 = compact inner spacing
- 16 = default spacing
- 20 = medium emphasis spacing
- 24 = section spacing
- 32 = large spacing
- 40 = hero spacing

## Screen padding
- Mobile horizontal padding: 16
- Large content screen horizontal padding: 20
- Bottom safe action spacing: minimum 16 above safe area

## Layout rules
- Every screen should have a visible top structure: title, subtitle, or progress context.
- Do not place more than 3 major blocks above the first scroll fold unless needed.
- Important CTA should be visible without hunting.
- Use cards to separate logic, not just decoration.

## Card spacing
- Card internal padding: 16
- Card list gap: 12
- Section gap: 24

## Form spacing
- Field-to-field gap: 16
- Label-to-field gap: 8
- Group-to-group gap: 24

## Grid guidance
- Prefer single-column mobile layout.
- Two-column layout is allowed only for tablet/web or compact comparison cards.
