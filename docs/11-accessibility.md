# Accessibility

## Core rules
- Minimum touch target: 44x44
- Text must remain readable at increased scaling
- Maintain strong color contrast
- Do not use color alone to communicate meaning
- Add semantic labels to important icons and actions

## Text
- Avoid tiny body text
- Keep line length manageable
- Use plain language

## Motion
- Respect reduced motion preferences where possible
- Avoid flashing or distracting transitions

## Forms
- Use visible labels
- Show inline errors clearly
- Use helpful, human error text

## AI and status content
- Eligibility state must include icon and text
- Official facts and AI advice should be visually distinguishable
