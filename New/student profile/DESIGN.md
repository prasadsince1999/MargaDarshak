# Child Profile - Bauhaus Neo-Brutalist

## Visual Thesis
The profile should feel like a student identity card turned into a useful control panel: raw, geometric, high contrast, and direct.

## North Star
"Form follows function." Every block should explain who the child is, what stage they are in, and what path they are following.

## Screen Structure
- **Top bar:** Compact app identity with menu and settings.
- **Identity hero:** Large portrait, name, mode, class, stream, board, and active path.
- **Snapshot strip:** Grade, roadmap progress, and goal count for quick scanning.
- **Academic stage:** Editable class, stream, board, and language.
- **Interests:** Strong color chips for goals, with one clear add action.
- **Roadmaps:** One live roadmap card with milestone and progress.
- **Preferences:** Language and guidance mode as separate editable settings.
- **Actions:** Edit profile, parent switch, and reset path.
- **Bottom nav:** Persistent mobile navigation with User highlighted.

## Colors
- **Ink (`#171717`):** Text, borders, active dark surfaces.
- **Paper (`#f5f0e8`):** Main background.
- **Muted (`#e7e0d4`):** Secondary surfaces and progress context.
- **Yellow (`#ffcc00`):** Primary action and active state.
- **Blue (`#0055ff`):** Exploratory or interactive emphasis.
- **Red (`#e63b2e`):** Reset/destructive emphasis.
- **Peach (`#f0c7bd`):** Warm academic accent.

## Typography
- **Display:** Space Grotesk for labels, titles, actions, and large profile identity.
- **Body:** Inter for supporting details.
- Use oversized type only where identity or decision priority matters.

## Component Rules
- Thick black borders, flat fills, and solid offset shadows.
- No soft shadows, glass, gradients, rounded cards, or decorative blur.
- Buttons must show physical press feedback.
- Chips are uppercase, compact, and color-coded.
- Keep text short enough to survive a narrow mobile viewport.

## Interaction Thesis
- Press states should feel tactile through offset-shadow compression.
- Edit/tune controls should read as real controls, not decorative icons.
- Roadmap and goal blocks should invite tapping without adding extra copy.
