# Mārgadarshak · मार्गदर्शक

## What families can explore

| Your question | Feature |
|---|---|
| What options fit my current stage? | Stage-aware roadmap and career exploration |
| What does this career involve? | Day in the life, learning topics and roles that open detail pages |
| What changes if I choose different subjects? | Subject Impact Simulator (currently labelled What-If Simulator in the app) |
| Which requirements should I check? | Eligibility Check and Exam Stack Planner |
| How do two routes compare? | Compare Paths |
| What foundations could I practise? | Foundation Check |
| Which documents and preparations need attention? | Future Ready Check and the related Documents Radar self-check |
| Can my family understand the cost and alternatives? | Parent Mode, local family discussion and Cost, Loan & ROI Calculator |
| What do students say about institutions? | Student Voice local feedback preview; reviewed public contributions are planned |

Local app scope includes eleven stages, from Class 9 through technical and higher-education routes and repeat attempts. Reviewed content coverage varies. Career pages help you explore possibilities; they do not prescribe one fixed route or guarantee a salary, admission or job.

## Try the Android preview

The **1.2.1 (build 4)** APK is an early-test release, not a Play Store launch. It supports Android 7.0 and later. Download from the release above, allow installation from that source if Android asks, install and start as Guest. Existing compatible installs can update; keep any important information separately before testing. Do not post personal identity documents or private student data in public issues.

This preview includes bundled exploration, local planning, practice and calculations. Check the applicable official notice before using admissions information. Connected Claude answers, live notice ingestion, server publishing, cloud family sync and subscription checkout are **not connected**. Optional sign-in availability depends on provider configuration; Guest exploration remains available.

**Subscription-based direction:** planned. Price, billing interval and included services will be announced before checkout is available. This build takes no subscription payment and does not simulate a purchase.

Known limitations: selected tests and a signed build do not establish production readiness; browser comparison layout has a small overflow under investigation, source-review gaps remain, and native installation/device behavior needs pilot validation.

## How reviewed guidance is planned to reach students

Official education notices → proposed structured changes → human editorial review → versioned catalogue release → relevant guidance in the student and parent app.

Local admin prototypes cover source review, pathway editing, institution records, moderation and AI-draft review. They are not a deployed administration service; admin routes are excluded from the default release. Planned Claude processing will propose explanations and updates for review, rather than certify eligibility or silently change a student's chosen plan. Private student evidence must remain separate from the public catalogue.

## Trust and access

Institutions cannot buy recommendation order. A self-check is not official verification. Empty or uncertain information should remain visible rather than become a fabricated score.
